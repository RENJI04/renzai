# Infrastructure

Phase 15B supplies production-oriented container builds, an internal-networked
Compose topology, hardened Nginx routing, optional OpenTelemetry collection,
Prometheus scraping, and repository-provisioned Grafana dashboards.

These files do not create a production certification or replace operator-owned
TLS, secret management, backup policy, capacity planning, or incident response.
See `docs/phase-15b` before deployment.
