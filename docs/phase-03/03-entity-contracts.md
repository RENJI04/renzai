# Entity contracts

These are logical records/value objects. Each row specifies ID, tenant, lifecycle, attributes/relations, invariant, classification/retention, owner and access. Legend: `A` = account lifecycle, `C` = configuration lifecycle, `S30` = security content/event default 30 days (configurable), `AU365` = audit default 365 days, `E` = expires/cleaned after credential validity, `D` = delivery metadata bounded cleanup. `P/I/S/X` = Public/Internal/Sensitive/Secret. All tenant readers must pass server-side RBAC and scoped query checks; only the named module writes. UUIDv7 is the default ID unless a row says random lookup.

| Concept (ID; tenant) | Lifecycle, key attributes and relations | Invariant | Class / retention | Owner; allowed readers → writer |
|---|---|---|---|---|
| User (`user_id`; global) | Active/disabled; email, normalized_email, verification state, created/updated | normalized_email unique; no account enumeration | S / A | users/auth; memberships → users |
| PasswordCredential (`credential_id`; user) | Password hash, algorithm/params version, changed_at | Argon2-class only; no plaintext | X / A | auth; none outside auth → auth |
| Session (`session_id`; user, active org selected per request) | Active/expired/revoked; random lookup, keyed verifier, created/last-seen/idle/absolute expiry, privilege version | verifier-only storage; expiry/revocation checked each use | X / E | auth; authz status → auth |
| PasswordResetToken (`reset_id`; user) | Issued/used/expired; random lookup, verifier, expiry | single use; issuance/response does not enumerate | X / E | auth; none → auth |
| EmailVerificationToken (`verification_id`; user) | Issued/used/expired; lookup/verifier/expiry | single use; optional deployment behavior | X / E | auth; none → auth |
| Organization (`organization_id`; self) | Active; name, slug, defaults, created/updated | slug unique; last Owner invariant | I / C | organizations; authorized modules → organizations |
| Membership (`membership_id`; organization) | Active/removed; user, role, joined_at | `(organization_id,user_id)` unique; last Owner protected | S / A | memberships; authz and authorized UI → memberships |
| Invitation (`invitation_id`; organization) | Issued/accepted/revoked/expired; target email/role, random lookup/verifier, expiry | bounded lifecycle; works without SMTP | X / E | memberships; invitee redemption/authorized admin → memberships |
| Application (`application_id`; organization) | Active/archived; name, privacy settings reference, created/updated | name unique within org; archived disallows new keys/traffic | I / C | applications; authorized modules → applications |
| Environment (`environment_id`; through application and organization) | Active/disabled; type development/staging/production, provider/fail-safe selection | one type per application; staging/production secure defaults | I / C | environments; gateway/keys/security → environments |
| ApplicationApiKey (`key_id`; through environment) | Active/revoked/expired; random public lookup, visible prefix, keyed verifier, created/last-used/expiry/revoked | secret shown once; lookup unique; no plaintext | X / C then revocation metadata | api_keys; auth gateway and authorized metadata UI → api_keys |
| SecurityEvent (`event_id`; organization/application/environment) | Created/retention-deleted; direction, source, correlation, privacy mode, safe content reference, action, result reference, time | tenant ancestry valid; no forced raw content | S / S30 | logs; incidents/analytics/authorized UI → logs |
| AnalysisResult (`analysis_id`; via event or transient context) | Completed; timestamp, risk/policy snapshots, action, findings, correlation | valid inspection only; profile version always present | S / S30 or transient | security; gateway/logs/incidents → security |
| Finding (`finding_id`; via analysis) | Immutable; detector ID/version, category, direction, confidence, safe evidence | no raw secret required | S / S30 | security; incidents/logs/authorized UI → security |
| DetectorVersion (`detector_id` + semantic version; global) | Published/deprecated; category, ruleset version, corpus reference | immutable after use; stable ID | I / version archive | detectors; security/risk → detectors |
| RiskProfile (`risk_profile_id`; organization or system default) | Active/archived; name, current_version | version selection audited | I / C | risk; security/admin → risk |
| RiskProfileVersion (`profile_id, version`; same tenant) | Draft/active/retired; weights, caps, thresholds, rule set | immutable once active; historical reference valid | I / version archive | risk; security/authorized UI → risk |
| RiskContribution (`contribution_id`; via analysis) | Immutable; finding/group, base, confidence factor, capped amount, rule | arithmetic reconstructs score | I/S / S30 | risk; security/authorized UI → risk |
| Policy (`policy_id`; organization with optional app/env scope) | Draft/enabled/disabled/archived; phase, priority, current_version | priority unique in effective scope+phase | I / C | policies; security/authorized UI → policies |
| PolicyVersion (`policy_id, version`; policy tenant) | Draft/active/retired; action, rationale template, immutable condition snapshot | activated version immutable; rollback selects old version | I / version archive | policies; security/audit → policies |
| PolicyCondition (`condition_id`; via version) | Immutable; field/operator/value/group | bounded grammar only; valid field/operator pair | I / version archive | policies; security → policies |
| PolicyDecision (`decision_id`; via analysis) | Immutable; phase, evaluated versions, matched policy/version or null, action, rationale | no match is allow only after valid inspection | I/S / S30 | policies; security/logs/incidents → policies |
| Incident (`incident_id`; organization, optional event) | Open/Investigating/Resolved/Ignored/False Positive; severity, title, assignee, timestamps | status transition valid; assignee same tenant | S / S30 default | incidents; authorized roles/analytics → incidents |
| IncidentTimelineEntry (`entry_id`; via incident) | Append-only; type, actor/service, timestamp, safe summary | correction appends; no raw secret | S / S30 | incidents; authorized roles/audit → incidents |
| IncidentComment (`comment_id`; via incident) | Append-oriented; author, sanitized body, timestamp | body size/content policy; no secret by design | S / S30 | incidents; authorized roles → incidents |
| ProviderConfiguration (`provider_config_id`; organization, optional app/env) | Enabled/disabled/deleted; name, kind, normalized target, model, timeouts, validation status/time | scope ancestry and SSRF validation | S / C | providers; gateway/AI/admin → providers |
| ProviderCredential (`credential_ref`; provider tenant) | Active/rotating/revoked; ciphertext, key ID | encrypted at rest; no plaintext response | X / C until deletion | providers; outbound adapter only → providers |
| AIAnalysisRequest (`ai_request_id`; incident tenant) | Queued/running/completed/failed; incident, actor, safe input reference | optional provider; privacy-approved snapshot | S / S30 | ai_intelligence; analyst/worker → ai_intelligence |
| AIAnalysisResult (`ai_result_id`; request tenant) | Completed/retention-deleted; labelled AI text, provider/model/version, timestamp | distinct from deterministic finding | S / S30 | ai_intelligence; analyst/incident UI → ai_intelligence |
| InAppNotification (`notification_id`; organization/recipient user) | Unread/read/expired; type, safe title/body, resource, timestamps | recipient belongs to tenant | S / S30 | notifications; recipient → notifications |
| WebhookDestination (`destination_id`; organization) | Enabled/disabled/deleted; normalized target, signing-key ref, event types | SSRF guard, owner/admin control | S/X reference / C | notifications; authorized admin/worker → notifications |
| WebhookDelivery (`delivery_id`; destination tenant) | Pending/leased/sent/retry/failed; event ID, attempts, status/time | `(destination_id,event_id)` unique; safe payload only | I/S / D | notifications; authorized admin/worker → notifications |
| AuditEvent (`audit_event_id`; organization) | Append-only then retention-deleted; actor/action/resource/time/correlation/safe metadata | correction is new event; no raw prompts/secrets | S / AU365 | audit; authorized roles → audit append port |
| OutboxEvent (`outbox_event_id`; organization) | Pending/leased/sent/dead; type, aggregate, safe ref, attempts/lease/time | unique event ID; at-least-once delivery | I/S / D | audit; dispatcher/operator → audit append/state port (producer requests append, dispatcher requests state change) |
| JobDelivery (`job_id`; organization) | Queued/running/succeeded/failed; event ref, idempotency key, attempt/time | revalidate tenant on execution | I / D | audit; named consumer/operator → audit delivery port (consumer requests state change) |
| PrivacySettings (`application_id`; organization via app) | Versioned value object; FULL/REDACTED/METADATA_ONLY, persist-safe flag | default REDACTED, persist-safe false | I / C | applications; security/logs → applications |
| RetentionSettings (`application_id`; organization via app) | Versioned value object; security-event/content retention days | security default 30; does not govern audit | I / C | applications; cleanup/audit read → applications |

The separate organization-level audit-retention override is part of `Organization` configuration, owned by `organizations`, and defaults to 365 days; `AuditEvent` cleanup reads that setting through an authorized port. No row permits a second module to write another module's private record. Cross-module transactions operate through use-case ports and one unit of work. Audit and outbox use a shared append interface with the initiating module as event producer; these records do not create a second source of truth for domain state.
