# Phase 15B scope

Phase 15B makes the frozen Phase 15A product operable as a serious self-hosted deployment. It adds production image builds, Compose orchestration, reverse proxying, bounded telemetry, dashboards, CI assurance, and operator runbooks. It does not alter detection, policy, Gateway, incident, analytics, AI intelligence, identity, tenant, privacy, API, or SDK semantics.

The authority chain remains Phase 1 product, Phase 2 architecture, Phase 3 contracts, and Phases 4–15A implementation evidence. Phase 16 and Phase 17 are out of scope. No historical migration is changed, no image is published, and no release is created.

Completion means the repository supplies a verified operational path; it is not a production certification. Operators still own TLS, secret management, backup schedules, capacity planning, upgrades, and incident response.
