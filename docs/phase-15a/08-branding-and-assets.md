# Branding and assets

The supplied Renzai logo is preserved as the canonical asset at
`apps/web/public/brand/renzai-logo.png`. It appears in authentication,
registration, onboarding, and the persistent shell. CSS sizing and cropping
provide compact icon and full lockup presentations without redrawing the mark.

The design uses the logo's cyan-to-mint identity as a restrained brand signal.
Semantic red, amber, green, and violet are reserved for security meaning rather
than decoration. No remote image, font, CDN script, large video, WebGL scene, or
third-party branding dependency was introduced, so the asset strategy remains
compatible with the hardened same-origin CSP.
