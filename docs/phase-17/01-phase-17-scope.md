# Phase 17 scope

Phase 17 prepares the first Renzai release without changing the frozen v1 product contract.
Phase 17A is local release preparation and audit. Phase 17B is a separate, explicit authorization
boundary for any external GitHub, registry, image, tag, or package publication.

The Phase 16 commit was the implementation baseline. Phase 17A may change release metadata,
licensing after owner approval, documentation, packaging, privacy/security blockers, and
reproducibility defects. It must not introduce new detectors, APIs, modules, Gateway features, or
autonomous behavior.

The release candidate is not production certification. The Phase 1 product, Phase 2 architecture,
Phase 3 contracts, and committed Phase 4–16 behavior remain the authority.
