# Release-candidate preparation

The [v1 RC checklist](../release/v1-rc-checklist.md) gathers product, testing, security/privacy,
documentation, and release-decision gates. License, version reconciliation, changelog, final
privacy/history audit, release artifacts, GitHub publication, tags, packages, and images remain
explicit Phase 17 blockers requiring user authorization.

Phase 16 performs no commit, push, tag, release, package publication, image publication, history
rewrite, or license change.
