# Architecture documentation

[Architecture](../architecture.md) contains eight editable Mermaid diagrams: system architecture,
Analyze pipeline, Gateway request flow, incident lifecycle, AI Intelligence flow, multi-tenant model,
self-hosted deployment, and observability. They reflect the frozen Phase 2–15B implementation and
show AI as advisory rather than enforcement authority.

The diagrams preserve fail-closed inspection boundaries, tenant ownership, internal data/telemetry
networks, loopback host publication, and privacy-bounded observability without implying unsupported
streaming, tool execution, agents, or autonomous remediation.
