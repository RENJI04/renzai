# Quick Start and API collection

The [Quick Start](../quick-start.md) uses the isolated local-demo Compose override, registration,
synthetic seed, one-time key creation, safe/malicious Analyze calls, seeded incident inspection,
Attack Lab, and reference app. POSIX and PowerShell differences are shown only where material.

The readable [Bruno collection](../../examples/bruno/README.md) covers session bootstrap,
organization/application/environment/key creation, policies, Analyze, Gateway, incidents, analytics,
and AI Intelligence. It embeds no credential; local variables hold one-time values. Collection docs
separate session + CSRF control-plane authentication from Bearer application-key data-plane auth.
