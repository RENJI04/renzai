# Assurance, performance, and limitations

[Assurance](../assurance.md) turns Phase 14 and Phase 15B evidence into a reader-facing inventory of
regression, live PostgreSQL/Redis, concurrency, Compose, observability, and local benchmark results.
It distinguishes measured local overhead from capacity, availability, and production SLA claims.

[V1 limitations](../limitations.md) consolidates the non-streaming text-only Gateway, absence of
tools/multimodal/agents/webhooks/notifications, deterministic coverage tradeoffs, optional provider
requirements, operator-owned deployment responsibilities, unpublished SDKs, and pending Phase 17
release decisions.
