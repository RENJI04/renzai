# README and demo assets

The root README is product-first: value, capabilities, screenshots, security flow, Quick Start,
workflows, SDKs, architecture, self-hosting, docs, explicit limitations, contribution/security links,
and concise status. Its hero reuses the approved Phase 15A Renzai logo asset. It avoids fake
package, license, certification, or release claims.

Official screenshots live in `docs/assets/screenshots/`, use a consistent viewport and Renzai Demo
Lab identity, and pass a manual privacy gate. [The recording storyboard](../demo-storyboard.md)
provides a reproducible 60-second sequence instead of committing a large or unreliable video binary.
