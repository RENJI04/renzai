# Security model and threat catalog

The [security model](../security/security-model.md) documents trust boundaries, opaque sessions,
CSRF, application keys, credential protection, tenant isolation, deterministic enforcement,
fail-closed behavior, SSRF controls, privacy/telemetry, and advisory AI.

The [threat catalog](../security/threat-catalog.md) explains all eleven V1 categories with safe
examples, evidence, policy possibilities, and limitations. [Claims and non-claims](../security/claims-and-non-claims.md)
make positioning explicit and avoid certification, perfection, SIEM/EDR/DLP, or zero-error claims.
